# Cyberboard Studio · MiaoCall Beta 14 公开测试版

本次公开当前 Beta 14 的源码快照、公开资源和已验证 macOS 包。公开标签为 `v1.0.0-miaocall.beta.14-public`；App 显示版本仍为 `1.0.0-miaocall.beta.14`。安装包与此前验收版本逐字节一致，无需为文档公开重新签名。此前私有提交历史、测试音频及桌面录制素材不随本次同步。

相较公开 RC2，新增经典深色 / 暖岛浅色双风格、可编辑键位与可读 Fn 功能、AI 输入框语音、可拖动喵娘与限定 Codex / Spotify 任务，以及布局、权限诊断、语音 TLS 和预览性能修复。喵唤默认关闭，仅支持 macOS；WorkBuddy、千问办公及豆包工作仍是规划入口。中英文 README、安装指南和当前界面截图已更新。

专门改善「AI 创作 → 键盘与外观」的进入卡顿。Beta 13 主要减少重复计算，但返回页面时仍会同步唤醒八份预览，首次进入的处理也可能挡住首帧；本版将页面呈现与照片处理分开。

- 先显示外观页面与可选择的照片卡片，再逐张准备灯效。照片和灯效共用固定的展示区域，准备时不挤动卡片；正在准备时显示状态。
- 照片去色与 83 颗轴灯遮罩按小批次处理，并定期让出执行时间给点击、滚动和页面绘制。离开页面、切换筛选或更新比较作品时取消旧任务；旧任务不能覆盖新结果。再次进入也不再同步唤醒八份渲染器。
- 每张比较卡片只解析实际显示的一帧顶屏与一帧轴灯，分别按各自原帧数计算。保留同作品、同一时刻的比较；完整作品、RGB、原始时序与槽位不变。处理失败保留可选照片，不循环重试。
- 继续保留主整机预览精度、八外观 contain 比例、静态缓存上限、隐藏暂停、原有工作区保存和退出等待。

验证：14 组前端/预览检查通过；新增首次进入和再次进入的首帧优先、无同步批量唤醒、单帧 RGB、独立顶屏/轴灯周期、处理中断/重进、最新快照覆盖及失败回退检查。分段处理与原同步处理的背景像素、全部 83 个光照遮罩逐字节一致。浏览器快速往返及外观布局检查通过，无文字裁切或横向溢出；macOS 签名 App 中已验证首次进入，以及连续三次「AI 创作 → 外观选择」往返。

macOS Apple Silicon 软件包通过严格签名、资源摘要、搬移启动、保存恢复与 TLS 完整性检查。不包含桌面录制 Demo；本轮不调用模型、麦克风、Codex / Spotify 或 USB。新包仅提供 macOS；Windows 历史 RC2 保留原样，不将其标为 Beta 14。Windows 原生界面仍待实机，不标为正式稳定版。
