# Cyberboard Studio · Beta 15

版本：`1.0.0-beta.15`。本版统一提供 macOS Apple Silicon、Windows x64 和 Windows 10 Compatibility x64，更新公开与私有仓库。[下载软件包与 SHA-256](https://github.com/maestrokaka/cyberboard-studio/releases/tag/v1.0.0-beta.15)

这是测试版。新增硬件功能需要对应 R6 和固件实机确认；离线协议、CI 或包检查不能替代真实 USB、麦克风与声学方向验收。

## 设备配置与同步

- 区分数据已发送、设备回执、键位读回与未知状态，不再把传输完成统一显示为全部内容已验证。
- 修正写入失败/中断后的灯效基线判断：一旦可能改动了设备，旧本机记录不能继续作为已确认基线。未知状态下不盲目重复整包写入。
- 新增独立「R6 声音」页：扬声器声道、麦克风拾音方向、降噪与音色使用独立短指令，不进入灯效整配置 JSON 写入。
- 声音选项初始为未知，只有明确设置后才显示本次回执。未发现或未接入的当前值查询不会用页面默认值代替；回显确认不等于实际拾音方向或音色已经实测。
- 新增本地麦克风测试：列出系统音频设备，按当前默认输入录音，最长 30 秒，可回放或清除。离开页面/取消/退出清理，不调用 ASR 服务。
- 扬声器校准放在高级区，开始前单独确认。需使用 AIROHAChat 默认输出，进入设备测试模式并开启双声道，等待后显示左右阻抗。结束不自动恢复原声道；未完成结果保持未知。
- R6 普通单键使用独立修改指令；长短按与宏使用独立表。新增、更新和删除先生成审核计划，绑定设备、固件、完整键位和高级表基底，并保留写前备份。发送后读回完整键码及可读取的高级表；读取不完整时不构造空表覆盖。
- 固件更新交接到 Angry Miao 官方网页，本版不在 App 内刷写固件。局部灯效写入协议仍待实机确认，未默认启用。

[R6 操作、状态含义与验收范围](R6_CONFIGURATION.md)

## 从公开 Beta 14 合并的喵唤能力

- Codex 从歌曲示例扩展为通用持久任务：工作目录、附件、继续追问、执行中补充、逐次授权、问题回答、结果与文件。
- 通过官方本机 app-server 创建和续接喵唤管理的会话，不读取认证文件，也不接管其他桌面聊天。Spotify 保留为 Mac 可选播放验证示例。
- Windows 原生支持任务、录音与桌宠，页面提供「安装 Codex → 登录 → 检测连接」，默认使用官方独立 CLI，无需先安装 Node.js 或 WSL。
- 桌面喵娘支持常驻/仅唤醒、自由拖动并记住位置、随主题切换气泡。常驻不会自动录音或启用按键监听。
- 三套服装及长发选项，共四组外观、32 张姿势；15 处停留互动、四种离线声线、60 条语音，声音默认关闭。
- AI 换装主动提交角色参考与服装描述，生成后先预览再应用。自定义 AI 衣装目前为静态立绘，不自动生成八个动作。

## 保留与兼容

- AI 创作继续作为首页；独立会话、不可变版本、局部修改、三槽草稿、八款外观与两种界面主题保留。
- 十款内置灯效及照片合成 GIF 的源 RGB、时序和顺序不变，全部可在本机作品库删除/恢复。
- Key 沿用普通本机文件、默认隐藏与显示按钮，不访问、解密或迁移旧 Keychain / DPAPI。
- 作品、任务、Key、工作区、设备记录与安装包分开。AI/喵唤录音最长 60 秒，R6 试听最长 30 秒，只在主动操作后采集并清理。
- 原有 Beta 14、RC2 和私有测试版本标签与附件保留。README 沿用 Beta 14 的 720p 内嵌演示，明确标注旧版范围；Releases 不放视频、原画质下载或工程素材。

## 安装与验证边界

完整解压对应平台 ZIP，核对同名 SHA-256。Mac 使用 ad-hoc 签名，未进行 Developer ID 签名/公证，首次打开按 [Apple 官方步骤](https://support.apple.com/en-gb/102445) 操作。Windows 建议先用普通 x64 包，缺少 WebView2 时使用随包的 Microsoft 安装器；Compatibility 包不扩大 .NET/Codex 的官方系统支持范围。

发布检查覆盖设备替身、异常点与状态迁移、回执和完整表校验、录音生命周期、前端交互、两种主题、照片比例、原生编译及软件包资源边界。此前 Windows CI 已验证官方 CLI 安装发现、真实 app-server 初始化和未登录状态查询，这不代表已登录用户并完成真实模型任务。

仍待实机确认：新增 R6 声音参数、前/后物理方向、扬声器校准、麦克风录放、宏/长短按和独立单键 USB 写入；Windows 真实 GUI、全局快捷键、用户登录与任务；更多固件和 R4 对应写入。未知状态不会包装成成功。
