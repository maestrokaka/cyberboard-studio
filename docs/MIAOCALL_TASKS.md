# 喵唤通用任务 · 私有 Beta

喵唤将确认后的语音或文字交给本机 Codex。Spotify 是可选演示；整理文件、总结资料、修改项目等任务使用 Codex 已有工具与连接。本版不接管其他 Codex 桌面聊天，也不承诺所有桌面 App 都有可用接口。

Mac 当前下载为 Tasks Private Beta 3；Windows Private Beta 1 正在准备，安装与官方 Codex 接入步骤见 [Windows 指南](MIAOCALL_WINDOWS.md)。安装私有 macOS 包时，请先阅读[私有版安装与权限说明](PRIVATE_MACOS_INSTALL.md)。当前包使用 ad-hoc 签名，首次打开需要 Control-click →“打开”；不需要关闭 Gatekeeper。

## 从一个任务开始

1. 安装并登录本机 Codex。打开「喵唤 · Beta」→「语音任务」。文字任务不需要语音 Key、麦克风或全局按键权限。
2. 选择工作目录。新任务默认只读；确实需要修改文件时，勾选「允许修改新任务的工作目录」。每个任务保存自己的目录和权限，后续追问沿用它们。
3. 输入任务，必要时添加最多 8 个文件。点击「交给 Codex」；也可以配置语音服务后，按住物理「·」说话，松开、确认文字再提交。先在任务记录中选择要继续的任务；选「新任务」会建立独立会话。
4. 执行步骤、返回文字和检测到的文件会显示在任务详情中。文件按钮通过 Finder（Mac）或文件管理器（Windows）定位，任务可以继续追问；执行中可用文字「补充指令」。语音补充需等当前轮结束。
5. Codex 请求额外权限或信息时，桌面气泡会提醒你打开任务详情。核对命令、目录和请求的权限，逐次允许或拒绝；不会自动批准。表单暂不能处理的连接器，需先在 Codex 配置后再试。
6. 点击停止或按 Esc，会请求正式中断。显示「正在停止」后等待结束；停止不撤销已经发生的文件修改。单轮最多 30 分钟，待答请求最多等待 10 分钟。

桌面角色可双击或右键「查看任务」。浅色气泡采用奶油底、棕色字、青绿主按钮；深色气泡采用深底和暖橙重点，与工作室设置即时同步，背景不再透出桌面文字。两种风格都保留桌面拖动与靠边换侧。

## 结果与记录

「Codex 已返回结果」表示官方任务已结束且返回了文字或实际存在的文件，仍需核对结果是否满足要求。它不等同于所有外部操作均已独立验证。Mac 的可选 Spotify 工具仍单独检查目标歌曲、播放状态与进度；Windows 不提供这套专用验证工具。只打开 App 不算播放成功。

- 喵唤的任务标题、文字、返回结果、命令摘要和文件路径保存在本机 `agent-tasks/`，与灯效会话、Key 文件分开。录音不会进入任务记录。Codex 官方运行时会保存自己的持久会话，沿用其账户和数据政策。
- 新任务会将确认后的文字、工作目录、所选附件路径发送给本机 Codex，再由其官方服务处理；所选目录与附件可能被任务工具读取。不要把不想提供的资料放入任务范围。
- 最多 50 个未归档、200 个总记录；每条记录最多 30 轮，长结果截取前 16000 字。可归档、恢复、导出，再删除不需要的归档记录。删除只移除喵唤的本机记录，不删除产物或 Codex 原会话。
- 产物列表检测最多 4096 个文件的变更，跳过依赖、Git、构建等目录；大型项目的完整结果以 Codex 返回和实际文件为准。目录消失时保留记录，恢复目录后可续接。断开后不会自动重做任务。
- 「复制诊断」只包含版本、系统、权限开关、任务状态数量与默认权限；不包含 Key、账户信息、文件路径、任务正文和原始服务回复。

本版使用官方 [Codex app-server](https://learn.chatgpt.com/docs/app-server)，创建和续接仅由喵唤建立的会话。额外权限采用一次请求或当前轮范围；不读取认证文件，也不自动扩大已选目录权限。工作目录权限不能当成文件读取的绝对隔离承诺，实际边界由本机 Codex 运行时决定。

## 已验证与正式版剩余事项

2026-10-25 使用本机已登录 Codex，在全新的临时合成目录完成：文件分类移动、资料摘要落盘、修复小项目并运行测试、沿同一会话补充测试。四轮均正式结束且文件检查通过。协议夹具另覆盖授权/拒绝、信息补充、错误线程、取消、超时、空结果拒绝与异常记录恢复；不将夹具当成真实系统权限测试。

Mac 包、实际窗口和主题气泡按发布说明验收。此轮没有写 USB、播放 Spotify、读取私人资料或录制声音。WorkBuddy、千问办公和豆包工作仍未接入。

距离正式版仍需：Windows 原生界面、麦克风、全局快捷键、真实 Codex 登录与任务的实测，R4/更多固件 USB 验收，弱网和长任务稳定性，以及升级后的权限验证。Mac 继续采用已选择的免费 ad-hoc 签名安装路线；付费 Developer ID 与公证暂不作为本轮发布前置条件，但首次打开仍有系统确认。当前 Mac 私有包保持原样，Windows 新包按单独的发布验收记录推进；没有把未验证事项标成通过。
