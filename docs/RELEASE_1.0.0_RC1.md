# Cyberboard Studio 1.0.0-rc.1

**正式版候选，GitHub prerelease：`v1.0.0-rc.1`。** 本版供 1.0 正式发布前试用与验收；不将尚未测试的平台、型号或模型组合标为稳定支持。

## 主要变化

- AI 创作独立成对话页面，保留参考图、简短历史、输入草稿和不可变灯效版本。可以选定基础版本，继续修改顶部、轴灯或两者。
- 局部修改用有界补丁编排，检查另一灯域与时序完整保留；旧版本不变，失败、取消和中断保留描述与已有结果。
- 增加会话搜索、版本预览 / 比较、停止 / 重试、指定版本导出、明确保存入库和工作台交付；空会话不能误保存旧作品。
- 工作台专注大整机预览、参数、JSON 和三槽草稿。会话、作品和槽位草稿独立，切换会话不再丢草稿。
- 键盘与外观独立成八张正面卡片，R4 / R6 筛选，同一作品同一帧比较；设备页通过子标签进入键位与同步记录。
- DeepSeek 将配方正文与思考信息分开计数，正文 128KiB、总传输 8MiB，并采用 low 思考强度与 24000 token 预算；修正累计 SSE 触发读取上限及思考耗尽输出预算的问题。
- MiniMax 兼容完整 stop 后关闭流的结束协议，并调整 M3 思考参数。新连接默认 M3.1 Flash Preview，已有手动保存的模型保持原选择。
- 工作区保存返回可等待的结果；正常退出 / 重载先完成保存，失败时取消关闭并可重试。正常旧工作区另存为私人 `workspace-before-1.0.json`；损坏的旧文件先按原始字节另存恢复副本，再写入新工作区。
- 延续十款已确认预设、作品库 / 回收站、JSON、单槽同步、当前键位保留、完整备份与计划；未重新修改预设 RGB 或写入键盘。

## 升级与数据

关闭旧 App 后再打开候选版，不同时运行两版访问同一工作区。现有作品、回收站、内置删除记录和槽位草稿保留；第一次成功写入 v2 工作区前保留 `workspace-before-1.0.json`。这份备份与新版会话、参考图、完整版本都留在私人数据目录，不上传 GitHub。升级不会自动探测或写入 USB。

Key 继续按服务保存普通本机文件，默认隐藏，可直接显示 / 隐藏。禁止系统凭据读取、解密、授权及兼容迁移；已有文本 Key 保留，只有旧系统记录时重新粘贴保存。Key 不包含在作品、工作区、导出或软件包中。
