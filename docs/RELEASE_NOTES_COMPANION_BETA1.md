# MiaoCall · Companion Private Beta 1

2026-10-24 · macOS Apple Silicon · 私有测试版

在公开 Beta 14 的灯效工作室基础上加入桌面陪伴与衣橱，保留 AI 创作首页、双风格、十款灯效、会话、键位编辑和原有语音任务。

- 常驻桌面 / 仅唤醒两种出现方式，大小可调，拖动记住位置，对话框靠屏幕边缘自动换侧。
- 橙白水手服、奶油针织 JK、雪白套装，另有水手服长发。四组共 32 个独立姿势。
- 15 处鼠标停留互动，带冷却与拖动保护；四种成年声线共 60 条离线语音，默认静音。
- 录音、转写和任务时暂停互动声音；透明边缘鼠标穿透。
- MiniMax image-01 参考角色 AI 换装，连接显式配置、先预览后穿上、支持取消和本机删除。自定义衣装当前为静态立绘。
- 只更新私有分支与私有 Release，不改公开 main，不上传视频、个人声纹源录音、Key 或设备资料。

详见 [使用与互动说明](MIAOCALL_COMPANION.md)。本版仍为 ad-hoc 签名、未公证的 macOS Beta；Windows 桌面宠物不在验收范围。本轮不操作实体键盘。
