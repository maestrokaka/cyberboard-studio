# MiaoCall Tasks · Private Beta 3

版本：`1.0.0-miaocall.tasks.beta.3`。仅更新私有仓库，公开 Beta 14 不变。

- 喵唤扩展为 Codex 通用任务入口：文字/语音交代任务、独立工作目录、只读默认、显式修改选项、所选文件、持久记录与继续追问。执行中支持补充文字指令。
- 展示执行步骤、待答问题、逐次权限请求、返回文字与产物。停止时等待中断，断开保留任务记录；不以模型首条回复当作外部操作已完成。
- Spotify 收入可选示例，普通任务不需要歌曲链接；播放示例保留真实回读检查。
- 修复 20 套 AI 衣装因 PNG/JSON 混排只显示 10 套的问题；应用桌面设置不再误穿未确认预览；切换姿势后，鼠标停在原位不会再次触发互动。
- 桌面气泡跟随经典深色/暖岛浅色，统一文字、描边、按钮和输入框，使用不透底背景。
- 增加任务归档、恢复、导出、删除归档记录与不含正文/路径/密钥的诊断。增加离线检查入口和 GitHub Actions。

真实本机 Codex 已完成四轮隔离任务验收：整理文件、摘要落盘、项目修复及测试、同会话继续补充测试。真实文件与会话标识均核对。附加回归涵盖原灯效会话、工作区、语音、主题、外观性能与预览比例。

详细操作、数据范围和正式版待验收项见 [通用任务说明](MIAOCALL_TASKS.md)。Mac 仍为 ad-hoc 签名、未公证；Windows 原生与 USB/R4 验收仍未补齐。Releases 仅提供 App ZIP 和 SHA-256，不包含视频或私人运行记录。
